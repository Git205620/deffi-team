# DeffiTeam 2.0

Telegram Mini App для каталога с корзиной и оформлением заказа.

## Запуск

```bash
npm install
npm start
```

## Переменные окружения

```text
BOT_TOKEN=токен_бота
ADMIN_CHAT_ID=id_чата_для_заказов
ADMIN_PASSWORD=пароль_админки
PORT=3000
```

Не добавляйте реальные секреты в Git. Заказы отправляются через Telegram Bot API в личный чат администратора.
