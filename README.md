# Telegram Mini App — Vape Shop

Мини-приложение для продажи электронных сигарет в Telegram.

## Что умеет

- Каталог товаров с наличием
- Корзина
- Самовывоз: **18/70 Зябь**
- Доставка по городу: **+250 ₽**
- Оформление заказа без оплаты
- Заказ приходит тебе в личку вместе с @username покупателя
- Админка прямо в приложении (добавление/редактирование/удаление товаров)

## Быстрый запуск

### 1. Создай бота
1. Напиши [@BotFather](https://t.me/BotFather)
2. Команда `/newbot` → придумай имя и username
3. Скопируй **токен** бота

### 2. Узнай свой Chat ID
1. Напиши боту [@userinfobot](https://t.me/userinfobot)
2. Скопируй свой **Id** (число)

### 3. Настрой сервер
Открой файл `server.js` и замени:

```js
const BOT_TOKEN = 'ВСТАВЬ_ТОКЕН_БОТА';
const ADMIN_CHAT_ID = 'ВСТАВЬ_СВОЙ_CHAT_ID';
const ADMIN_PASSWORD = 'admin123';   // придумай свой пароль
```

Или используй переменные окружения:
```
BOT_TOKEN=...
ADMIN_CHAT_ID=...
ADMIN_PASSWORD=...
```

### 4. Установи и запусти
```bash
cd telegram-vape-shop
npm install
npm start
```

Сервер будет на `http://localhost:3000`

### 5. Подключи мини-приложение к боту
1. Залей проект на любой хостинг с HTTPS (Railway, Render, Vercel, Timeweb, VPS и т.д.)
2. В @BotFather:
   - `/mybots` → выбери бота → **Bot Settings** → **Menu Button**
   - Или команда `/setmenubutton`
   - Укажи URL своего мини-приложения (например `https://твой-домен.com`)

Также можно использовать команду `/newapp` в BotFather для создания полноценного Mini App.

## Как пользоваться админкой

1. Открой мини-приложение
2. Нажми кнопку ⚙️ в правом нижнем углу
3. Введи пароль (по умолчанию `admin123`)
4. Добавляй, редактируй и удаляй товары

## Структура заказа, который приходит тебе

```
🛒 Новый заказ

👤 Покупатель: @username
📱 Телефон: +7...
Имя: ...

• Elf Bar 1500 × 2 = 900 ₽
• HQD Cuvie × 1 = 380 ₽

💰 Итого: 1530 ₽
📍 Самовывоз: 18/70 Зябь
```

## Важно

- Товары с наличием 0 не показываются покупателям
- Все данные товаров хранятся в файле `products.json` на сервере
- Для продакшена лучше поставить MongoDB / PostgreSQL / Supabase, но для старта JSON-файла достаточно
