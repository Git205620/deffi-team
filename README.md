# Deffi Team — Telegram Mini App

## Файлы проекта
- `server.js` — сервер и API товаров/заказов.
- `app.js` — интерфейс, выбор склада, корзина и админ-панель.
- `index.html` — разметка приложения.
- `style.css` — оформление.
- `products.json` — резервная копия каталога из 8 товаров.
- `package.json` — зависимости и команда запуска Railway.

## Что включено
- Выбор склада 18/70 или 32/01 при входе.
- Запоминание выбранного склада и обновление надписи склада в шапке, карточке товара и корзине.
- Отображение остатков только выбранного склада.
- Поиск товаров в админке по названию, бренду и описанию; фильтр по категории.
- Редактирование товара, цены, фотографии и остатков по двум складам.
- Серверная проверка наличия при оформлении заказа и обновление остатков.
- Управление статусами заказов и возврат остатков при отмене.
- Чёрно-золотое оформление, снег и гирлянда.

## Настройка Railway
В Variables задаются `BOT_TOKEN`, `ADMIN_PASSWORD`, `ADMIN_CHAT_IDS` (числовые Telegram ID администраторов через запятую). Секреты не хранить в GitHub и не отправлять в чат.

## Важно о данных
`products.json` в архиве — резервная копия каталога на момент сохранения. Если положить его в корень репозитория, сервер сможет прочитать его при первом запуске, когда файла данных ещё нет. Перед заменой существующего каталога сделайте резервную копию актуальных товаров и заказов.

Файловая система Railway без подключённого постоянного Volume может очищаться при пересоздании/перезапуске контейнера. Для постоянного хранения товаров и заказов нужен Persistent Volume либо внешнее хранилище.

Автоматический никотиновый подарок в этот архив не добавлен.
