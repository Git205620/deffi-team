# DeffiTeam 2.0

Telegram Mini App для каталога товаров, корзины и оформления заказа.

## Запуск

```bash
npm install
npm start
```

Настройте переменные окружения на сервере:

```text
BOT_TOKEN=новый_токен_бота
ADMIN_CHAT_ID=id_чата_для_заказов
OWNER_TELEGRAM_ID=1497750238
PORT=3000
```

Владелец по умолчанию: Telegram ID `1497750238`. Владелец может назначать и отзывать администраторов в приложении по их числовому Telegram ID. Администраторы могут добавлять, редактировать и удалять товары, менять цены, остатки и HTTPS-ссылки на фото.

Админские запросы проверяются на сервере по подписанному `Telegram.WebApp.initData`. Для работы авторизации задайте `BOT_TOKEN` (новый токен из BotFather) и запускайте Mini App через Telegram. Для HTTPS-ссылок на фото используйте публичные изображения.

Не коммитьте токен бота или другие секреты. Токен ранее находился в исходниках, поэтому его следует отозвать через BotFather и создать новый.
